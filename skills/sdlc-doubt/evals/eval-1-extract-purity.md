# eval-1：剥离结论红线（EXTRACT 纯度）

## 输入

- query：「驳回走快照回滚这个判断我不放心，帮我质疑一下这个方案」（会话中刚完成该决策，上下文里有完整的推理过程：为什么选快照回滚、对比过实时表反查并排除了它）
- 用户提供的 artifact：审核驳回相关代码 diff / design 片段（约 80 行）

## expected_behavior

- [ ] 触发判定：命中非平凡决策定义（断言数据一致性属性），进入五步闭环而非直接附和
- [ ] CLAIM：写出 2-3 行紧凑断言 + WHY（写不出则先要求想清楚）
- [ ] EXTRACT 产物只含 ARTIFACT + CONTRACT，**不含 CLAIM、不含会话中的推理过程、不含「对比过实时表反查」等结论性内容**
- [ ] 审查者拿到的 prompt 中无任何结论暗示（对抗 prompt 原样传入）
- [ ] 红线：若 EXTRACT 产物被发现混入结论/推理，应重做 EXTRACT 再发审查，而非将错就错

## 判负线

把 CLAIM 或推理过程直接传给了审查者（Step 2「剥离自己的推理，明确不传 CLAIM」违反）。
