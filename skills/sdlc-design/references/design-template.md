## A 级全量骨架

产物 = 头部字段 → §0 → §1-§8。逐节填充；表格列禁止删减（列是下游消费契约）。

### 头部字段

```markdown
# <需求名> 技术设计（design.md）

> 风险分级：<A|B>（升级说明：<若设计期升级，附影响面证据与升级日期>） ｜ 设计日期：<YYYY-MM-DD>
> 输入锚点：digest / audit / pm-checklist：`sdlc/<需求名>/intake/xxx-<日期>.md`（口径漂移时以此判断是否回溯重审）
> 偏差回写规则：实现中仅**影响 ER / 接口契约 / 公共组件 / 公共资产**的偏差回写本文档，且仅重审受影响切片；局部偏差切片内记录即改不回写。组件接口调整不算偏差（脚手架不是合同）。
> 体检问题去向权威：本文档落盘后，audit 问题去向以头部「体检问题去向」表为准；parent prd 的去向表（如存在）注明「后以 design 为准」。
```

**体检问题去向**（存在 audit 时必填；audit 全部 🔴/🟡 须有行，🔵 可省；无行即设计不自洽）：

| 体检编号 | 级 | 去向 | 落点 | 说明 |
|---|---|---|---|---|
| 体检.P04 | 🔴 | 已承接 | 功能.F07 | PM 答复：公示开始后才能执行颁奖 |
| 体检.P11 | 🔴 | 转 Q 表 | 确认.Q3 | 公示时长口径待定 |
| 体检.P15 | 🟡 | 本期不做 | — | 理由：修改窗口归下期 |

**Q 表**（三选一状态，注明来源）：

- 复用：parent prd 已有 Q 表 → 「Q 表来源：parent prd §6（复用，不在本文档重复）」+ 增量项追加
- 生成（轻量链路无 prd）：按下表生成并维护——来源 = pm-checklist 未答复项 + digest §假设清单「假设」类条目（推断类不入表）

| 编号 | 问题 | 当前假设 | 阻塞范围 |
|---|---|---|---|
| Q1 | 评选结果公示时长 | 72 小时 | 阻塞 F07 / 无阻塞（仅展示口径） |

> 跨产物引用统一 `命名空间.编号`（需求.FR-xx / 体检.P-xx / 功能.F-xx / 确认.Q-xx / 设计.D-xx），禁止裸写他产物编号。

### §0 方案总览与备选

至少一个关键决策写选型对比——**无备选、无 trade-offs 的设计是 implementation manual，不如不写**（设计文档的价值在记录决策依据，供 gate 评审与后续维护者理解「为什么不是另一条路」）。

| # | 决策点 | 选择 | 弃选 | trade-off | 依据功能点 |
|---|---|---|---|---|---|
| 1 | 参评资格校验时机 | 提交时校验 | 审核时校验 | 提交即拦截：用户即时反馈 vs 审核工作量后移 | F03、F04 |

### §1-§6 技术骨架主体

继承三段式第二段骨架（结构以本模板为准）：

**§1 数据模型落地**：表结构现状（已建/待建）、DDL 约束要点（唯一约束/索引策略及理由）。

**§2 接口契约（分级粒度，每行挂 F 编号 + 消费的业务规则/主线节点）**：

- 写接口（字段级：字段名/嵌套结构/口径来源/校验归属；不含校验注解细节）：

| F 点 | URL | 字段（嵌套逐级列） | 口径来源（业务规则/ER 字段） | 校验归属（声明式校验/校验器） |
|---|---|---|---|---|
| F03 | /contest/works/save | … | 规则§4 / ER.works.* | 基础注解 + 校验器跨字段 |

- 读接口（出参字段清单 + 口径来源；展示细节留切片）：

| F 点 | URL | 出参字段清单 | 口径来源（挂 D 表决策） |
|---|---|---|---|
| F01 | /contest/works/get_list | … | D5 统计口径 / D9 推导 |

> 被锁功能点（Q 表硬阻塞）的契约行按「当前假设」产出，行尾标 **「锁定待拍板（确认.Q-xx）」**。

**§3 公共资产清单（六类，每项标：被哪些切片消费 / 归属哪个切片交付）**：

| 类别 | 资产 | 内容要点 | 消费切片 | 交付切片 |
|---|---|---|---|---|
| ① 枚举与码表 | WorksStatusEnum（跨域公共枚举扩展值 → **声明影响面**） | code/label 对齐 ER 与实体注释 | C2、C3 | 骨架切片 |
| ② 常量与 key 空间 | 锁 key / 定时任务 taskId / 错误消息文案模板 | 统一收口，禁止切片内散落定义 | 全部 | 骨架切片 |
| ③ 命名空间约定 | URL 前缀 / 包路径 / 类名前缀 / 校验 profile 前缀 / 方法名避让 | … | 全部 | 骨架切片 |
| ④ 公共 DTO 子结构 | 文件信息体 / 列表行公共字段 / 快照结构 | 多切片同构结构只定一版 | … | 骨架切片 |
| ⑤ 共享存量扩展影响 | 改哪些公共 Req/组件 | 受影响 profile/域清单 | … | 对应切片 |
| ⑥ DDL 与索引脚本 | 表清单 + uk/idx 策略 | 落库脚本路径 | … | 骨架切片 |

### §7 实施切分约束

> **spec 降级声明置顶**：项目任务框架的切分规范（如 `.trellis/spec/` 切分规范，见 [trellis-handoff.md](trellis-handoff.md)）未落盘时，拆分纪律以本章为准；已落盘时两者一致（本章是 spec 的需求级实例）。
>
> 本章是「实施切分约束」——拆分规则随设计交付，任务框架拆 subtask 时**必须遵守**；但任务编排（建任务/排期/状态管理）归任务框架。

**7.1 切分建议表**（公共资产清单非空时：**第一个切片必须是骨架切片**，交付枚举/常量/DDL/包目录/公共子结构，完成前业务切片不得启动）：

| 顺序 | 切片 | 覆盖功能点 | 依赖 | 共享物归属（本切片创建的公共类/枚举/常量/DDL；复用谁的；在途锚点） |
|---|---|---|---|---|
| C1 | 骨架 | — | 无 | 创建：… |
| C2 | … | F03/F04 | C1 | 复用：C1 枚举/常量 |

**每个切片验证口径（开发完成验证四件套）**：compile/boot/冒烟/回归——命令承载 `sdlc/env/dev.md`，走 `/sdlc-test dev <需求名>` 留档；C 级切片 compile+boot，A/B 级全量。对照各切片技术级验收标准。

**7.2 横切功能点核验矩阵**（横切功能点不单独建切片——无独立触发角色、代码落点分散多接口的功能随宿主切片交付）：

| 横切功能点 | 预期联动 | 落点宿主切片 | 核验结论 |
|---|---|---|---|
| F08 状态流转 | save 注册 / edit 重注册 / terminate·delete 移除 / 处理器幂等守卫 | C2、C3 | （宿主完成后补记） |

> **核验结论补记时点**：任务框架 check 阶段（至迟 sdlc-test static 前），由宿主切片核验后逐行补记；本矩阵文件须登记进 check 上下文清单（见 trellis-handoff.md）。

## B 级 mini 裁剪表

B 级（digest 头风险分级为 B 的功能需求——判定口径见 [SKILL.md](../SKILL.md) 路由节；与 playbook「影响 ≤2 层且 ≤3 文件」的轻量任务判定公式无涉：后者决定是否走三段式链路，此处只决定设计裁剪深度）产出一页以内 mini 设计，裁剪规则：

| 章节 | 裁剪 |
|---|---|
| 头部字段 | **不裁**（Q 表/体检问题去向/输入锚点/偏差回写声明全保留） |
| §0 备选 | 简化：一个关键决策一句话对比即可，可省表格 |
| §1 数据模型 | 不涉及表结构则省；涉及则只列变更字段 |
| §2 接口契约 | 保留（读写分级照做，F 点挂接照做） |
| §3 公共资产 | 只列涉及类别（通常 ①③），归属列保留 |
| §4/§5 | 合并为一行「新增/复用清单」 |
| §6 D 表 | 裁剪类别：只答适用类别（通常并发控制/权限与数据范围），其余标「不适用」 |
| §7 切分约束 | 简版：单切片直做（无骨架先行问题）或两切片小表；横切矩阵仅横切点存在时保留 |
| §8 | 保留（一行风险说明） |
