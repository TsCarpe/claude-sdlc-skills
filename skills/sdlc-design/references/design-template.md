```markdown
> 偏差回写规则：实现中仅**影响 ER / 接口契约 / 公共组件 / 公共资产**的偏差回写本文档，且仅重审受影响切片；局部偏差切片内记录即改不回写。组件接口调整不算偏差（脚手架不是合同）。

```

**设计期问题去向表**（判的是**出口**，不改入表规则——pm-checklist 未答复项、digest 假设清单「假设」类条目、parent prd §6 既有项照常入表、不出表；其中不满足硬阻塞定义的，「阻塞范围」列写「无阻塞（仅 <口径>）」、不锁；已有条目的阻塞范围与本表判定不一致时，设计按本表锁定，并在落盘回报里提请需求侧订正该列，不代改既有行）：

| 问题 | 出口 | 落点与标注 |
|---|---|---|
| 口径已有定论、只是文档结构没落位（功能点没编号、规则没挂功能点、digest 缺节） | 提示回需求侧补文档，不立 Q | §8 记一行并提示（无平台定稿 → 重跑 sdlc-intent；有平台定稿 → 走平台变更单）；设计按该定论落笔，不新增功能点编号 |
| 口径没有定论、须产品拍板，且答案不同则写接口契约形状不同（入参必填性或字段集合、写接口或其分支的有无、唯一约束或表结构、状态能否流转） | 转 Q 表（硬阻塞） | 入 Q 表；受该口径影响的契约行与 D 表行（不分读写）按当前假设产出并标「锁定待拍板（确认.Qn）」；「阻塞范围」列写到分支粒度；一行内只有部分字段受影响的，整行标并注明字段范围；不受影响的行不标 |
| 口径没有定论、须产品拍板，但取哪个都不改契约形状（上限数值、排序、文案） | H 假设承接 | 不立 Q（已入表的留在表内、标无阻塞）；D 表该行类型标 H，写接受条件；落盘回报里列出请用户顺手确认；已有 需求.Axx 的沿用其编号 |
| 纯技术选择（存储形态、缓存、索引、算法） | 设计自决 | D 表该行类型标 C 或 H，不立 Q |
| 超出本期范围 | 不立 Q | §8 记边界，回 parent prd Out of scope（无 prd 则回 digest 范围外） |

## C 级轻量方案

C 级不产 design.md，产一页 `sdlc/<需求名>/design/plan.md`。头部保留：输入锚点（digest/audit/pm-checklist/standard 日期；audit 存在时，standard 无则记「无」）、体检问题去向（audit 🔴/🟡 逐条落点）、Q 表或未决口径、偏差回写声明。主体一页以内：

| 项 | 内容 |
|---|---|
| 影响接口 | 方法+路径 / 入参 / 出参 / 逻辑要点（逐接口一行） |
| 落点 | 文件/类（存量勘察结论；新建写「新建」） |
| 验证 | compile + boot 口径（compile 命令取自项目构建配置，无依据写「待确认」；boot = 健康探测）；`sdlc/env/dev.md` 未建写「待按 env-template 创建」 |
| 未决口径 | 阻塞项（标 Q 表编号；无写「无」） |

产出后走 `/sdlc-gate <需求名>` C 档主会话自查（不扇出），0 条 issue 也须人工确认后放行；`/sdlc-test dev` 前补最小 cases（P0 + 双向追踪表）。
