# eval-3：无版本信息的本地文档

## 输入

- query：「梳理一下这份需求」（本地 markdown 文件路径，文件头无版本号/修订时间）
- 文档特征：中等篇幅，含角色表和功能清单，部分状态流转缺失；文件曾梳理过一次（存在旧梳理文档，梳理日期较早）

## expected_behavior

- [ ] 本地文件直接 Read，不尝试 lark-cli；「评论区」字段记「无评论」（本地输入）
- [ ] 缺失的流转/触发/字段标 ❓，禁止自行补全
- [ ] 复用旧梳理文档体检时，因原文无版本信息，向用户展示梳理日期并确认原文是否有更新，而非静默复用
- [ ] 用户确认无更新后才复用；确认有更新则建议重梳理
- [ ] 边界：不读代码库、不做技术设计、不评估技术方案合理性
- [ ] 产出语言跟随文档语言（中文）
