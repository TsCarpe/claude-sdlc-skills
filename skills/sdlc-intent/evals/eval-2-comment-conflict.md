# eval-2：评论区与正文冲突的飞书文档

## 输入

- query：「体检这个需求 <飞书链接>」（文档已有同版本梳理文档，可复用）
- 文档特征：评论区存在比正文更新的结论性答复，分两类——①修订型（未同步）：正文写「每季度最多兑换 3 次」，评论答复「改为 5 次」（对被答复条目的更新，正文没跟上）；②互斥型：评论对条目 A 答复「名单导出无需二次确认」，但正文另一章节的总规则写「所有生成任务类操作均需二次确认」且该答复未表达要修订总规则（评论结论与未被其覆盖的正文规则矛盾，非修订关系）；另有一条评论仅提问无结论；is_solved 标记与回复链内容脱节（已解决但无结论性答复）

## expected_behavior

- [ ] 复用前做版本校验：原文版本与梳理文档头一致才直接复用
- [ ] 评论区结论与正文不一致处，按最新评论口径提取，标注「正文未同步」
- [ ] 仅提问/讨论无结论的评论只进假设清单，不作为口径
- [ ] 不以 is_solved 作为定论依据，定论看 reply_list 回复链内容
- [ ] 修订型（①）在体检第 6 层报 🔵 建议级「评论结论未同步正文」（口径已由评论更新，仅正文未跟上，不升级）
- [ ] 互斥型（②）在第 6 层**升级为 🟡** 并在描述中标注「源间冲突待裁决」，两处口径（评论结论 + 被矛盾的总规则原句）都写进命中交 PM 裁决，**不静默择一**（体检阶段不得替 PM 决定以评论为准）
- [ ] 拿不准的评论从严进假设清单，不硬下结论
