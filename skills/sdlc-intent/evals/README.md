# sdlc-intent 评估场景

对齐官方 Agent Skills best-practices 的评估驱动开发：每个场景 = 输入 + 预期行为清单。
用法：新会话加载 skill 后，按场景给出输入，逐条核对 expected_behavior。

- eval-1：完整 PRD 梳理+体检（已有验收样本）
- eval-2：评论区与正文冲突的飞书文档
- eval-3：无版本信息的本地文档（复用校验分支）
- eval-4：原型附件与正文功能面缺口（html demo 附件下钻）
- eval-5：v1.2 原文预处理与块级锚点（XML→doc.json→条款级出处→锚点附加→失败回退）
- eval-6：缺失类缺陷检查（第 7 层外部参照层：对称缺格/有消无录/数据无源/引用断链/跨模块不对齐/有录无消 + 误报对照）
- eval-7：阶段0 参照系构造（ref-tables 四表 + 冲突格纪律 + 裁剪规则 + D1/D3 来源标注）
- eval-8：阶段1 视角推导（perspectives 任务卡 + 扇出喂料 + D2 收敛纪律：反向锚点/不与 D1 重复/待裁决只追问）
- eval-9：需求风险分级（评分卡 A/B/C 提议+拍板 + digest 头字段与 FR 分级列 + 分级路由 + 拿不准从高/降级需证据）
- eval-10：决策类型标注（C 约束/H 假设：第 4 层隐含约束未声明 + 类型列初判问号 + PM 答复定型 + C→护栏候选/H→验证项流转落点）

评分：expected_behavior 命中数 / 总数。任何「脑补原文没有的流转/字段」直接判失败（梳理纪律红线）。
