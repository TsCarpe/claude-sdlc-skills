# eval-10：决策类型标注（C 约束 / H 假设：初判问号 + PM 答复定型 + 流转落点）

## 输入

- query：「体检这个需求 <本地 md 文件>」
- 文档特征（评选活动类中性虚构）：
  - 「生成作品分享链接」功能：全文未提及链接重复生成、撤销、未登录者访问的期望行为（隐含约束未声明——组织默认知识）
  - 「获奖名单公示」写了"公示期结束后撤下"，但撤下后评委已评分数据是否保留未定义（隐含约束）
  - 「作品列表加载策略」写"建议分页展示"（实现选择——分页 vs 虚拟滚动待定，属可按反馈调整的假设）
  - 「作品标签筛选支持多选」（纯功能澄清类，无定性意义）
- 用户在 PM 答复环节回应：「分享链接业务上必须可撤销且未登录不可见；列表加载策略你们定，压测能过就行」

## expected_behavior

- [ ] 隐含约束命中：分享链接的重复/撤销/越权三条中 ≥2 条在第 4 层「隐含约束未声明」命中，类型列标 `C?`（初判带问号）
- [ ] 实现选择类（列表加载策略）命中时类型列标 `H?`，不误标为 `C?`
- [ ] 纯澄清类问题（多选筛选确认）类型列标 `—`，不强行打 C/H
- [ ] 类型列独立于状态列：类型 `C?` 的条目状态仍走 `[ 待处理 ]` / `[ 问PM ]` 既有流转，两列各自维护
- [ ] H 类澄清措辞问"接受条件"而非"唯一答案"（如「本期按分页实现，按什么标准判定可接受？」），C 类问"业务上必须是什么"
- [ ] PM 答复后定型：分享链接条目去问号成 `C`（撤销=约束）；加载策略条目成 `H` 并带接受条件（压测通过）
- [ ] 定型 C 的条目在交互收尾提示流转落点：人工持体检报告调 sdlc-guardrails 按候选编写规则；定型 H 的转测试验证项，且 H 不进护栏
- [ ] 判定口诀应用正确：公示数据保留被推翻时是事故（数据丢失）→ `C?`；加载策略被推翻是改进 → `H?`
- [ ] 与第 7 层边界：「全文未提及撤销」属组织默认知识未写明（第 4 层本项），不误报到第 7 层缺失类
