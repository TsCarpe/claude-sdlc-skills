# eval-8：阶段1 视角推导（perspectives 任务卡 + 扇出 + D2 收敛）

## 输入

- query：「体检这个需求 <本地 md 文件>」（digest 头风险分级：A 级，评分依据功能点 ≥5，含计算指标）
- 已有产物：digest（含 §7 规则表 FR-01~FR-05）+ refs-<日期>.md（阶段0 已构造，候选清单 C1-C6，其中 C3 为 ⚠️冲突格且两行标「依赖待裁决」）
- 文档特征（评选活动类中性虚构）：FR-02 规定「获奖作品按专家评分加权排序」但专家评分的录入/来源无任何章节；模块 A 消费「机构认证状态」而认证由外部系统发放且正文仅一句"认证状态以外部为准"；FR-04「每机构最多申报 5 件作品」无并列/重复申报边界；某模块数据流完整无缺口（反例）

## expected_behavior

- [ ] 判定为 A 级（分级路由读 digest 头「风险分级」）：跑阶段1，用 Agent 工具扇出实现者/测试者子代理（全新上下文）
- [ ] 喂料纪律：子代理 prompt 只含任务卡+模块切片+refs 相关行+FR 表，**不含**会话全文与其他模块命中
- [ ] 产出中间制品：实现者视角的模块数据流草图、测试者视角的断言草稿（推导任务而非提问清单）
- [ ] 候选为缺口式表述（「原文缺 X，推导在 Y 处中断」），非开放式「要不要考虑 X」
- [ ] **反向锚点**：每个候选附定位尝试（检索过何处未见）；能定位到答案的不报——专家评分来源、认证状态边界保留，「数据流完整模块」不产出候选（反例不误报）
- [ ] 不与 D1 重复：C1-C6 已覆盖的点不重复报；⚠️冲突格只生成「以哪处为准」追问、不基于任一方展开（违反判负）
- [ ] 只留动手级：好奇级问题丢弃（如「要不要支持导出」类本文档未涉及的能力发散）
- [ ] 候选回主会话交第 7 层判定，成立的命中标 D2、按第 7 层降级纪律定级；报告中 D2 条目句末标「（推导发现）」且不占必须确认档顶部
- [ ] B/C 级对照（同会话给出 ~10 行小需求，风险分级 B 或 C）：跳过阶段1 不扇出
