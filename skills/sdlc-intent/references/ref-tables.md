# 参照表构造规范（体检阶段 0）

> 缺失类检测 = 构造参照系 + 双向 diff。本文定义体检 Step 2 的产物：四张参照表 + 候选清单，落盘 `sdlc/<需求名>/intake/refs-<YYYYMMDD>.md`。参照表是**检查脚手架**——忠实提取与可推导标注，不做缺陷判定（判定在第 7 层做）。

## 原料与构造姿势

- 原料：digest 8 区块（核心概念表 / 功能点地图 / 状态机 / 规则口径表）+ 原文；有 doc.json 时出处写到条款级，构表按需定向拉相关块（含公式的块、配置类章节），不全量重读
- **忠实优先**：表内容优先照抄原文事实（字段在哪录入、被谁引用）；需要推导才得出的格子标 `（推导）` 并给一句依据——推导出错不会被当成原文事实
- 构造粒度：只收**参与业务规则或计算**的字段/指标，纯展示性文案不进表

## 四张表

### 1. 数据字典（必建）

| 字段（实体.字段） | 录入处 | 消费处 | 来源 |
|---|---|---|---|
| <实体>.<字段> | <表单/导入/配置章节> | <计算/展示/规则/导出，逐处列> | <本系统录入 / 导入 / 外部同步 / 🤔> |

三查（每查都是第 7 层候选）：
- **有录无消**：录入处非空、消费处空 → 候选
- **有消无录**：消费处非空、录入处与配置入口空 → 候选
- **无源**：来源 🤔 且非本系统录入 → 候选

### 2. 指标字典（含计算指标/报表列时建）

| 指标 | 公式 | 输入 | 输入的配置入口 | 精度 | 报告落点 |
|---|---|---|---|---|---|

任一列空 → 候选（有消无录 / 计算口径未定义——后者归第 3 层，标注清楚不重复报）。

### 3. 平行结构矩阵（存在对称维度时建）

识别对称维度（**通用定义，勿绑定具体业务叫法**）：文档自己声明的同类并列结构——同模板重复的并列章节、同一字段的多枚举值、多角色/多端/多租户/多组别。

| 功能面 \ 维度值 | 甲 | 乙 | … |
|---|---|---|---|
| <配置项/报告板块/操作> | ✅/—/⚠️ | | |

缺格 = 该格 `—` 而同行兄弟有 `✅` → 候选（对称缺格）；正文显式声明有意差异的不算缺格。

### 4. 引用图与外部依赖（必建，轻量）

| 引用语句 | 指向 | 状态 |
|---|---|---|
| 「<下文另行说明/如上所述/见 X>」 | <落点章节> | ✅有落点 / 🔗断链 |

外部依赖清单：正文出现的外部系统/外部数据/既有系统数据引用，逐条记「被谁依赖 + 声明的来源 + 入口有无」。

## 裁剪规则

| 触发特征 | 建表 |
|---|---|
| 任何需求 | 数据字典 + 引用图 |
| 含计算指标/报表数值列 | + 指标字典 |
| 存在对称维度 | + 平行结构矩阵 |
| 某表触发但构造不出（如并列结构识别失败） | 在 refs 文件头记「<表>未构造（原因）」，不静默跳过 |

## 冲突格纪律（构表时撞到口径冲突）

同一概念在两处口径不一（取值/规则/操作不同）时：**禁止择一填入**，格子写 `⚠️冲突[<出处A>|<出处B>]`，该行立即成为高优先级候选（冲突比缺格严重——缺格是"不知道"，冲突是"两个答案"）；依赖该格的下游行（用它的公式、展示、规则）标 `依赖待裁决`，后续只追问、不基于其中一方展开。

## 候选清单与来源标注

refs 文件末尾产「候选清单」：每条 = 表名 + 命中规则 + 定位（条款级出处）+ 一句话。进入第 7 层语义判定后：

- **D1（结构 diff）**：来自候选清单的命中——可机械复现，证据硬
- **D3（维度命中）**：第 7 层（及其他层）按检查项通用模式直接推导的命中

报告明细中每条命中标源（D1/D3），用于统计各引擎贡献（口径见 report-template 撰写规则）。
