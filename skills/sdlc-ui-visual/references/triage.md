# 比对产物读法与差异分类（步骤 4/5 的判定依据)

> 本页承载两件事：compare.py 产物怎么读（含不可判定的升级路径），以及差异「修 vs 保留 vs 问用户」的分类决策表。不引用其他 references。

## A. 统计指标怎么读

compare.py 每轮产出（stdout + 落盘 `stats.txt`）：

| 指标 | 用途 |
|---|---|
| mean diff（0-255） | 全局噪声水平基线；轮间改善度量的主指标之一 |
| >30 差异像素占比 | 捕捉局部大偏差不被均匀摊薄；改善度量的主指标之二 |
| 热区网格矩阵（0-9 级，附格中心坐标） | 定位偏差区域；中心坐标用于映射回 DOM 元素 |
| 暗像素计数（--box 内） | 小元素墨迹密度对比（图标视觉等价性） |

**改善判定**（步骤 5 轮次纪律）：mean diff 与 >30 占比**两个指标连续 2 轮均不降** = 无改善 → 停止修改重新分析。

## B. 热区读法

- 大片 6-9 级集中在某列 → 横向结构性错位（宽度/对齐问题）
- 整行 6-9 → 纵向错位（多行/少行/行高问题）
- 散点 1-2 级 → 内容性差异（数据不同），通常可接受
- **先修让大片高热区降级到 0-2，再抠散点**
- 热区格中心坐标 → 浏览器 `elementFromPoint(x, y)` 映射到具体 DOM 元素定位根因

## C. 可接受噪声（不修）

- **文字光栅化差异**：设计稿字体渲染略饱满——判定标准：位置/字号/字重一致 + 局部差异呈均匀文字像素分布（无位移重影）
- 数据内容不同（演示数据 vs 真实数据）造成的散点差异

## D. 不可判定的升级路径

暗像素扫描命中过少（如 <10 像素）= 元素太细/太浅，**视为「不可判定」**，禁止就此下「一致」结论。升级手段（按序）：

1. `--box` 裁剪放大 ≥3 倍出拼图，视觉判读「形状/大小/颜色」三项
2. 与基准图同法放大对比 + 暗像素计数相对比较（如实现墨迹仅为基准 30% = 视觉不等价，哪怕几何尺寸全等）
3. 仍无法判定 → 记入 run.md「待人工确认」，汇报时列入保留偏差

**小元素⚠ 打标项一律走本节 D 路径**，与第 1/2 道比对结果无关（区域平均稀释：10×10 图标在 45×40 统计区的差异会被摊薄到噪声水平；数值等价 ≠ 视觉等价——API 的 10×10 是 SVG box，font-size:10px 是 em box，字形只占 em 框约 60%）。

## E. 差异分类决策表（修 vs 保留）

| 差异类型 | 处理 | 示例 |
|---|---|---|
| 结构性（布局/尺寸/溢出） | **修** | 栏宽不符、横向溢出 |
| 组件级样式 | **修** | 按钮形态、圆角、间距、文案 |
| 内容性（数据不同） | 保留 | 演示数据 vs 真实数据 |
| 需求性差异 | 保留并说明 | 实现按需求隐藏了设计稿某行 |
| 应用壳层（侧边栏/顶栏/容器宽度） | 保留并说明 | 不属于本目标样式对齐范围 |
| 功能性新元素（设计稿没有/多出的开关） | **问用户**后跳过 | 记入 run.md 待办与拍板记录 |
| 共用组件细节 | 权衡后保留或最小增量 | 行距改动会影响所有调用方页面 |
| 功能合理性与设计稿冲突 | 保留并说明 | 固定高度滚动区 vs 设计稿 hug |

分类结果逐条登记 run.md 差异台账（编号/现象/分类/去向），用户已拍板的分类重开会话不得推翻。

## F. 局部放大对比
