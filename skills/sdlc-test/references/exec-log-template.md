# 执行留档模板（exec-log）

产出位置：`sdlc/<需求名>/test/reports/<日期>-r<N>/exec-log.md`（与截图 screenshots/ 同目录）。当日志写，不做事后汇总——每用例执行完立即追加一段。

```markdown
# <需求名> 执行留档 R<N>

> 日期：YYYY-MM-DD　环境：test（<URL>）　分支/版本：<后端 / 前端>
> 用例：sdlc/<需求名>/test/cases.md（N 条）
> 本轮范围：R1 全量 ｜ R<N> 回归（重跑上轮失败/疑似/阻塞 + 缺陷未闭环项：TC-xx,TC-xx,…；--all 全量）

## 执行记录

### TC-01 <用例标题>

- 结果：通过（R1）
- 证据：screenshots/TC-01-01.png；POST /v1/xx → code=0；SQL：activity 表新增 1 行（id=123）
- 备注：（偏差/观察/证据降级说明；失败时写实际表现与初判原因，并登记缺陷编号）

### TC-07 <用例标题>

- 结果：失败（R1）→ BUG-03
- 证据：screenshots/TC-07-01.png；接口返回 code=1001…
- 备注：实际表现…；初判原因…

（每用例一段，按执行顺序追加）

## 本轮小结

- 执行：x 条（通过 a / 失败 b / 阻塞 c）
- 新增缺陷：BUG-xx, BUG-xx（详见用例文件「缺陷跟踪」表）
- 闭环缺陷：BUG-xx（本轮重跑通过，已更新状态）
```

## 口径

- **结果四态**：通过 / 失败 / 阻塞 / 未执行，标注轮次 `（R<N>）`
- **缺陷行自解释**：本轮小结的缺陷行格式 = `BUG-xx〔端〕完整陈述`，陈述含现象+预期差异+发生位置；禁纯编号引用（"详 exec-log"类字样只能附在完整陈述后）
- **证据引用**：截图文件名 + 接口（方法+路径+关键响应）+ SQL 摘引；证据降级（仅截图/视觉判断）必须注明；console error 的处置（已定位原因/与本案无关的依据）在备注留痕
- **失败用例**：写清实际表现 + 初判原因 + 缺陷编号（BUG-xx，登记到用例文件「缺陷跟踪」表，四要素在 report 阶段补全）
- **失败初判参考（网络分诊）**：接口返回 code≠0 → 业务校验拒绝，按错误码反查校验规则；HTTP 4xx → 请求侧问题（参数/URL/登录态失效）；HTTP 5xx → 服务端问题，转查后端日志不在浏览器侧猜；请求缺失 → 确认前端是否真的发出（拦截/触发条件不满足）；超时 → 响应时间/载荷大小。分诊结论写入「初判原因」，仍拿不准标"疑似"
- 回归轮重跑通过的失败项：更新用例文件缺陷跟踪表（状态=已修复、修复轮次），本 log 记录重跑证据
- 断点续跑：中断后重进，从头部「本轮范围」与最后一条记录的下一条继续
