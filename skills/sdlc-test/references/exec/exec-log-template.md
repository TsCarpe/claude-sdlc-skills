# 执行留档模板（exec-log）

产出位置：`sdlc/<需求名>/test/reports/<日期>-r<N>/exec-log.md`（与截图 screenshots/ 同目录）。当日志写，不做事后汇总——每用例执行完立即追加一段。

```markdown
# <需求名> 执行留档 R<N>

## 元信息

| 日期 | 环境 | 分支/版本 | 用例 |
|---|---|---|---|
| YYYY-MM-DD | test（<URL>） | <后端 / 前端> | sdlc/<需求名>/test/cases.md（N 条） |

- 本轮范围：R1 全量 ｜ R<N> 回归（重跑上轮失败/疑似/阻塞 + 缺陷未闭环项：TC-xx,TC-xx,…；--all 全量）

## 结果总览

（轮次初始化时按本轮范围**预填全部 TC 行，结果列留空**；执行期只更新对应行的结果/截图单元格，不插行不删行——空结果行即断点续跑锚点）

| TC | 优先级 | 结果 | 缺陷/闭环 | 截图 |
|---|---|---|---|---|
| TC-01 | P0 | ✅ 通过（R1） | — | TC-01-01.png |
| TC-02 | P0 | ❌ 失败（R1）→ BUG-01 | BUG-01 新增 | TC-02-01.png |
| TC-07 | P1 | | — | — |

## 执行记录

（每用例一段，按执行顺序追加）

### TC-01 <用例标题>

- 结果：✅ 通过（R1）
- 证据-页面：screenshots/TC-01-01.png（<页面断言要点>）
- 证据-接口：POST /v1/xx → code=0
- 证据-落库：xx 表新增 1 行（id=123）
- 证据-console：无 error
- 复现锚点：（仅通过的 P0/P1/BUG 关联用例必填）关键按钮/label/可见文本 + 接口 URL + 前置数据键，如：入口=「创建比赛」按钮；名称输入 getByLabel('比赛名称')；提交=POST /v1/activity/save；业务键 name='创建验证-01'
- 备注：（偏差/观察/证据降级说明；失败时写实际表现与初判原因，并登记缺陷编号）

### TC-07 <用例标题>

- 结果：❌ 失败（R1）→ BUG-03
- 证据-页面：screenshots/TC-07-01.png
- 证据-接口：返回 code=1001…
- 证据-落库：—
- 证据-console：—
- 备注：实际表现…；初判原因…

## 本轮小结

- 执行：x 条（通过 a / 失败 b / 阻塞 c）
- 新增缺陷：BUG-xx, BUG-xx（详见用例文件「缺陷跟踪」表）
- 闭环缺陷：BUG-xx（本轮重跑通过，已更新状态）
```

## 口径

- **结果四态+疑似**：通过 ✅ / 失败 ❌ / 阻塞 ⛔ / 疑似 ❓（含 flake疑似）/ 未执行（总览表留空），标注轮次 `（R<N>）`；**图标仅用于 exec-log**，回填 cases.md 不带图标
- **总览表预填制**：轮次开始按本轮范围预填全部行（G-xx 组成员逐条单列）；执行期只更新单元格；范围外新增用例在表尾补行
- **证据四类分行**：`证据-页面 / 证据-接口 / 证据-落库 / 证据-console` 四行固定，某类无证据写 `—`；证据降级（仅截图/视觉判断）必须注明；console error 的处置（已定位原因/与本案无关的依据）在备注留痕
- **缺陷行自解释**：本轮小结的缺陷行格式 = `BUG-xx〔端〕完整陈述`，陈述含现象+预期差异+发生位置；禁纯编号引用（"详 exec-log"类字样只能附在完整陈述后）
- **G-xx 组合并执行**：组内每条用例独立成段（`### TC-xx`），结论不埋粗体长句；组共享上下文（基准流说明/全程未提交）在组内首段备注写明
- **复现锚点**（spec 资产化的翻译输入，见 `references/spec/spec-guide.md`）：通过的 P0/P1/BUG 关联用例必填——记录语义选择器（按钮文案/label/可见文本，与页面实词一致）、接口 URL、前置数据业务键；不记 XPath/CSS 内部类名
- **失败用例**：写清实际表现 + 初判原因 + 缺陷编号（BUG-xx，登记到用例文件「缺陷跟踪」表，四要素在 report 阶段补全）
- **失败初判参考（网络分诊）**：接口返回 code≠0 → 业务校验拒绝，按错误码反查校验规则；HTTP 4xx → 请求侧问题（参数/URL/登录态失效）；HTTP 5xx → 服务端问题，转查后端日志不在浏览器侧猜；请求缺失 → 确认前端是否真的发出（拦截/触发条件不满足）；超时 → 响应时间/载荷大小。分诊结论写入「初判原因」，仍拿不准标"疑似"
- 回归轮重跑通过的失败项：更新用例文件缺陷跟踪表（状态=已修复、修复轮次），本 log 记录重跑证据
- 断点续跑：中断后重进，从头部「本轮范围」与执行记录最后一段的下一条继续（锚点=TC 记录段与总览表空结果行，不依赖小结）
