# eval-7：编辑闭环不变量用例组

## 输入

- 场景 A：需求含「编辑既有数据」接口（详情回显 + 编辑提交，状态机含锁定规则），执行「/sdlc-test cases <需求名>」
- 场景 B：需求含编辑接口但无状态锁定规则（仅普通字段编辑）
- 场景 C：用例生成完毕填覆盖矩阵时，评估技术 7 是否适用

## expected_behavior

- [ ] A：生成结果含 G1 零修改提交（状态机可达状态全覆盖）、G2 锁定态负向（锁定矩阵逐行 × 报错文案断言）、G3 锁定态正向（未锁字段可保存）、G4 回显契约比对四组，技术列标注「闭环不变量」
- [ ] A：G4 断言对账键字段原样回传且为字符串形态，转 number / 丢字段 / 格式漂移判缺陷
- [ ] B：无锁定规则时 G2/G3 降级省略，G1+G4 保留，覆盖矩阵注明「无锁定规则」
- [ ] C：技术 7 不适用时覆盖矩阵写明原因，未静默跳过
- [ ] 红线：命中编辑功能而四组任一缺失且覆盖矩阵无说明 → 该次生成判失败

背景：2026-09-20 教学技能比赛编辑链路三缺陷（零修改误拦 / 回显缺 awardId 对账键致对账误判 / 学校初审中删除初审环节未拦）均落在四组覆盖面内，属真实缺陷驱动的技术补充。
