# sdlc-gate 评估场景

对齐官方 Agent Skills best-practices 的评估驱动开发。五个场景覆盖分歧产出、关卡拦截、独立生成纪律、裁决分层、风险分级路由五条主线。

- eval-1：设计×用例口径不一致 → 交叉审查应产出第三类分歧并升级用户
- eval-2：review 状态≠已放行 → sdlc-test static/exec 应被拒绝（关卡互认）
- eval-3：用例生成被要求参考设计文档 → 应拒绝（独立性红线）
- eval-4：同根因跨角色发现 → 应合并为一个裁决单元；低严重度观察项进备案区不占裁决；soft 依据降级进批量组
- eval-5：风险分级路由（A/B/C 分档扇出 + 双重判级 B→A 升级回写 + C 级自查清单与独立性如实标注 + 存量无字段按 A 级）

评分：expected_behavior 命中数 / 总数。任何「第三类分歧未升级用户就自行裁决」「用例生成读了设计文档」或「soft 依据且严重度=高的条目被移出裁决焦点」直接判失败（纪律红线）。
