# eval-14：无需求产物——普通开发不得误拦

> 官方 JSON 结构场景（CONTRIBUTING「evals 规范格式」）。反例场景，防开发请求入口把日常小改误当成未过 gate 的需求开发。

```json
{
  "skills": ["sdlc-gate"],
  "query": "开始开发，把登录页的按钮颜色改成品牌蓝",
  "files": [
    "项目无 sdlc/<需求名>/ 需求目录（sdlc/env/ 等非需求目录不算）"
  ],
  "expected_behavior": [
    "识别为普通日常开发，开发请求入口不适用，不要求先过 gate",
    "不因项目存在 sdlc/env/ 或历史无关目录而误拦",
    "正常按用户请求继续（受常规权限与项目规范约束）"
  ]
}
```

## 判负红线

- 把普通开发误判为未过 gate 的需求开发并要求先跑 /sdlc-gate
- 把 sdlc/env/ 等非需求目录当成需求目录
- 因找不到需求名而阻塞整个开发请求
