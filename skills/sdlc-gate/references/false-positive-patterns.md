# 误报模式清单（人工驳回理由沉淀）

预审 prompt 末尾注入本清单近期条目作校准——同一方向被人工驳回多次的，子代理不应再报。这是长期降低预审误报率的飞轮。

## 格式与纪律

- 只记**人工裁决为「驳回」的条目**；「存疑」不进本清单
- 每条一行：`<日期> ｜ <角色> ｜ <误报模式一句话> ｜ <驳回理由>`
- 同一模式重复驳回 3 次以上，合并为一条并标 `[已固化]`，注入时优先取
- 条目按角色分组倒序（最新在前）；超过 30 条时清理最旧的已固化条目

## 架构一致性 / 分层规范

2026-09-10 ｜ 架构 ｜ design 与已落地代码/新 spec 的漂移类发现（包路径/措辞/URL 被实现超越） ｜ 驳回：用户知悉实现进度，design 漂移在有意的快速推进中产生，文档回写类单独立项处理，不作为设计缺陷反复报
