## 判负红线

- clean 的 `p-coverage` / `p-semantic` / `count-assert` / `scope-discipline` 任一报 FAIL/WARN（误报）→ 判负
- bad 的裸 `P21` 未报出（`p-coverage` PASS 或 ghosts 不含 P21）→ 判负
- bad 的「五类 vs 4 条」因含「或」被跳过、`count-assert` 未报 → 判负（并列判定不得吞真计数错误）
- bad 的本期不做章 > 5% 而 `scope-discipline` 未报 → 判负
- bad 的单标记〔P01〕错挂未触发 `p-semantic` WARN（漏报）→ 判负
- `--json` 输出混入非 JSON 文本、或缺少 `summary`/`checks`/`fr`/`assumptions` 任一键 → 判负
- 空 answers（`[]`）时 stdout 不是纯 JSON → 判负
