# sdlc-platform 评估场景

对齐官方 Agent Skills best-practices 的评估驱动开发。四个场景覆盖状态机路由与人工关、澄清附图处置、子命令幂等防护、四项引导四条主线。全部为官方 JSON 结构形态。业务示例用中性虚构（商品/订单类），平台地址以 `<平台地址>` 占位。

- eval-1：无子命令有迭代名、卡 step=adopt → 只查状态、adopt 话术原文、草稿原样展示、等人确认才采纳
- eval-2：澄清题人选推荐项+附图 → 读图把图内事实写 extra、只写看得见的、不替人决定、不连答
- eval-3：对 importing 中的卡重发 import → 不重发 import_requirement、按状态说话术、不进 30 秒轮询
- eval-4：整条消息只有 new → 两段式引导（先话术句原文、再五行代码块），不先问迭代名、不调工具

评分：expected_behavior 命中数 / 总数。任何「未经人确认调写工具」「重发与卡状态不符的动作」「替人决定/编造图外内容」「先问迭代名再给引导」直接判失败（纪律红线）。
