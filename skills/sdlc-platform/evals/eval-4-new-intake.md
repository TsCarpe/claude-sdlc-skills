# eval-4：只发 new 的四项引导

```json
{
  "skills": ["sdlc-platform"],
  "query": "/sdlc-platform new",
  "files": [],
  "expected_behavior": [
    "不调用任何 MCP 工具，也不先问迭代名或任何一项",
    "回复第一段是「对用户怎么说」里「new 且没给迭代名」那一句原文（新建迭代需要一次给齐迭代名、项目名称、需求名、来源。……需求名不要和迭代名写成同一个。），一个字不改",
    "回复第二段是三个反引号围住的 Markdown 代码块（聊天里出现复制按钮），块内五行：/sdlc-platform new、迭代名：、项目名称：、需求名：、来源：——每项单独一行",
    "四项不并成一行，不写成普通段落，说明文字不写进代码块",
    "不发迭代名之后不自行补项目名称等默认值凑四项"
  ]
}
```

## 判负红线（任一命中整场景失败）

- 先问迭代名（或任何一项）再给引导
- 把四项并成一行或写成普通段落
- 调用 `sdlc-in:import_requirement` 等任何工具
- 说明文字混进代码块
